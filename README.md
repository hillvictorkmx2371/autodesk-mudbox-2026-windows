## Getting Started

A standard Mudbox session can follow this sequence:

1. Start Autodesk Mudbox.
2. Load an existing project or create a new sculpting scene.
3. Establish the primary form, then build additional detail with the sculpting tools.
4. Paint or project textures to develop the model's surface information.
5. Switch subdivision levels whenever broad changes or fine refinements are needed.
6. Apply retopology when a cleaner mesh is required for later pipeline work.
7. Save successive versions so earlier revisions remain available.

For texture-focused projects, define the high-level sculpt before adding materials and surface details. When preparing a model for another stage of the pipeline, perform retopology after sculpting so the resulting geometry better matches the intended workflow.
